# AI Tools History Archive — AI-era Registry Specification

Status: planned / mandatory future-work reference

## Goal
The archive must document tool/service lifecycle with evidence rather than compete with AI-generated product summaries.

## Required work
- Preserve the existing data model, content policy, source/evidence policy and reviewed publication boundary.
- Track lifecycle where supported: launch -> major capability/availability/pricing restriction changes -> deprecation/shutdown announcement -> shutdown -> export/migration/replacement/successor.
- Preserve original source claims and uncertainty; expose provenance and last verification.
- Provide deterministic per-tool machine-readable JSON from canonical data.
- Strengthen structured filters for provider, tool type, status, change/shutdown reason, dates, migration/replacement and evidence quality where supported.
- Add Compare for lifecycle/change history, not subjective best-tool ranking.
- Add Stats for lifespan, shutdown/change reasons, provider distribution, migration/replacement availability and registry quality/coverage.
- Automated discovery may stage candidates but not publish unreviewed canonical facts.

## Non-goals
No AI-generated canonical history, subjective model/tool rankings, prompt buttons or chatbot-first archive.

## Mandatory reference
Future product, data-model, validation, source/evidence, UI and roadmap work must consult this file. Existing stricter source/content rules prevail.
